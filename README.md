Janae's Personal Website

Hi, I'm Janae! I made this website to share a little about myself and the things I enjoy, like gaming, robotics, graphic design, anime, and musicals.

About the redesign

I gave each page a clearer layout and added the same menu to all four pages. My hobbies are shown in cards, and the layout changes to fit phones, tablets, and computers.

Technologies

-HTML for the page content
-CSS for the colors, layout, and mobile styles
-Git and GitHub for saving and reviewing changes

 How to open the website

Open `index.html` in a web browser. The menu at the top links to the other pages.

 Different screen sizes

I used CSS media queries to adjust the layout on smaller screens. The menu and hobby cards rearrange to fit, and the pictures shrink to fit their space.

## Reflection

I liked seeing my original pages turn into a website that feels more organized I added clear sections, a menu on every page, and cards for my hobbies. I also learned that using one CSS file makes it easier to keep the pages looking similar. My photos stay in the project, so their image links still work when I open the site.

The hardest part was fitting everything onto a small screen without making it hard to read. I used media queries to change the layout, and I had to adjust how the menu, pictures, and hobby cards fit when there was less space. Checking the different screen sizes helped me notice what needed to change. I learned that a mobile page needs more than smaller text the layout needs to change too.
