Janae's Personal Website

Hi, I'm Janae! I made this website to share a little about myself and the things I enjoy, like gaming, robotics, graphic design, anime, and musicals.

About the redesign

I gave each page a clearer layout and added the same menu to all four pages. My hobbies are shown in cards, and the layout changes to fit phones, tablets, and computers.

Technologies

- HTML5 for the page content
- CSS3 for colors, layout, themes, and mobile styles
- JavaScript for interactivity and DOM manipulation
- Git and GitHub for saving and reviewing changes

JavaScript enhancements

1. Dark and light mode: A theme button switches the whole website and saves the visitor's choice in local storage.
2. Live date and time:The website displays the current local date and time and updates it every second.
3. Hobby search: The portfolio page filters the hobby cards while the visitor types in the search box.
4. Interactive FAQ:About-page FAQ buttons expand and collapse answers with accessible state updates.
5. Contact message preview: The contact form retrieves visitor values, counts remaining message characters, and creates a preview dynamically.

 How to open the website

Open `pages/index.html` in a web browser. The menu at the top links to the other pages.

 Different screen sizes

I used CSS media queries to adjust the layout on smaller screens. The menu and hobby cards rearrange to fit, and the pictures shrink to fit their space.

## Reflection

I liked seeing my original pages turn into a website that feels more organized I added clear sections, a menu on every page, and cards for my hobbies. I also learned that using one CSS file makes it easier to keep the pages looking similar. Organizing pages and assets into separate folders makes the project easier to navigate, and my photos stay in the project so their image links still work when I open the site.

The hardest part was fitting everything onto a small screen without making it hard to read. I used media queries to change the layout, and I had to adjust how the menu, pictures, and hobby cards fit when there was less space. Checking the different screen sizes helped me notice what needed to change. I learned that a mobile page needs more than smaller text the layout needs to change too.
